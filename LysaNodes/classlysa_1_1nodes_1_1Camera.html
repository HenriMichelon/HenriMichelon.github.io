Casts a ray from the camera's world position toward a target point and returns the first MeshInstance intersected, or nullptr if the line of sight is unobstructed. The ray length equals the distance to target, so no geometry beyond it is tested.

Parameters

Returns

std::set<std::shared_ptr<MeshInstance> > rayCast ( const std::shared_ptr< MeshInstance > &  target,
bool  all = false 
) const

Casts a ray from the camera's world position toward each of the 8 corners of target's world-space AABB, and returns all MeshInstances that blocked at least one ray. Target is ignored as an occluder.

The ray length for each corner equals the distance to that corner, so no geometry beyond it is tested. Duplicate occluders appear only once in the result.

Parameters
targetThe MeshInstance whose AABB corners are used as ray targets
allDon't stop at the first occluder, returns all the occluders using the full ray length
Returns
All distinct MeshInstances that blocked at least one corner ray, in order of first occurrence.
