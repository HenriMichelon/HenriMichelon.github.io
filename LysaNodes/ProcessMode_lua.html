Detailed Description

Constants that control when a node receives process and input callbacks.

Lua full name: lysa.nodes.ProcessMode

Constants

integer INHERIT
 Inherits the processing mode from the node's parent. Default for any newly created node.
 
integer PAUSABLE
 Stops processing when the scene tree is paused. Inverse of WHEN_PAUSED.
 
integer WHEN_PAUSED
 Processes only when the scene tree is paused. Inverse of PAUSABLE.
 
integer ALWAYS
 Always processes, regardless of the paused state. Inverse of DISABLED.
 
integer DISABLED
 Never processes. Completely disables all processing callbacks. Inverse of ALWAYS.
